# Focus Explorer
1. Open chrome://extensions and turn on Developer mode.
2. Click "Load unpacked" and select this folder.
3. Pin the extension, open it, and start a focus session.

Hit your daily goal to extend your streak and earn an expedition day. Regions unlock at 0, 3, 7, 14 and 30 goal days.
Stack: JavaScript, Chrome APIs (storage, alarms, declarativeNetRequest).
